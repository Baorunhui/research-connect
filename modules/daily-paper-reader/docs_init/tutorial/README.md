# 使用教程

## 论文日报

打开左侧栏底部的齿轮，点「保存并生成日报」。首页上也可以直接点「生成日报」。写的时候页面上会显示进行到哪一步。每天北京时间 02:30 会自动写一次。

## 总结一篇论文

打开论文总结，贴上论文链接或上传 PDF。写好后会打开一篇阅读页。

## 写一篇综述

打开综述，填一个研究主题。通常要几分钟。如果勾选了细读全文，会更久。写好后会出现在左侧列表。

## 查他引和小红书

这两个在网站首页的另外两个入口，不在论文日报里面。
