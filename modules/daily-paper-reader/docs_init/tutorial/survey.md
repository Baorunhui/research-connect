# 综述链路说明

本页讲解「综述生成」功能的完整流程：一个研究主题（可选附一篇种子论文），
到生成一篇带引用编号、落盘为站点正式页面的领域综述报告，中间经过哪些阶段、
每个阶段用什么技术、有哪些质量护栏。

## 前置准备

综述由本地后端（`python src/local_server.py`，默认 8567）驱动，纯静态部署不可用。
首次使用前需要构建 Kaggle 快照索引（默认召回主路）：

```bash
# .env 配置 Kaggle 凭据（免费账号即可，Account → Settings → API 创建）
# KAGGLE_API_TOKEN=KGAT_xxx
python scripts/build_kaggle_arxiv_index.py --download
```

一次性下载约 2GB 快照并建立本地 SQLite FTS 索引（约 15 分钟，产物在
`archive/kaggle_arxiv/`，已 gitignore）。快照由 Cornell 官方持续同步但存在
周级滞后，建议每周重跑一次刷新。未建索引时 Kaggle 路自动跳过并在进度中提示，
综述仍可用本地库 + 种子引文链路（覆盖会窄很多）。

## 整体流程

```
输入：研究主题（任意语言）+ 种子论文（可选，推荐）
   ↓
① 种子分析（可选）：抓种子全文 → LLM 结构化分析
   （任务定义/输入边界/任务范式/英文查询组/引文 arXiv id/数据集名）
   ↓
② 查询规划（无种子时）：1 次 LLM 调用把主题转写成 5-8 条英文检索查询
   （中文主题直查英文文献库会全军覆没，这一步是防主题漂移的关键）
   ↓
③ 多路召回融合（RRF + 去版本号去重）
   ├─ Kaggle 快照 FTS 粗筛（默认主路：314 万篇本地检索，毫秒级，支持全历史回溯）
   ├─ 本地 Supabase 库（BM25+向量，窗口默认截 180 天）
   ├─ 种子引文直取（arXiv Atom，免 token，种子背书排序）
   └─ DeepXiv 语义检索（默认关，勾选后补被引数与最新论文）
   ↓
④ 召回-主题贴合度熔断：查询核心词在候选池的字面覆盖率 < 0.2 直接终止
   （宁可不生成，不可生成与参考文献脱节的幻觉综述）
   ↓
⑤ 语义粗排：万级候选 → 300 篇（本地 bge 编码，与查询向量取最大余弦）
   ↓
⑥ Reranker 精选 30 篇（失败回退 RRF 序）
   ↓
⑦ 逐篇结构化抽取：relevance<4 丢弃 + 任务范式门（跨范式论文剔除）
   ↓
⑧ 聚类（肘部法则 KMeans + LLM 簇命名）→ 核心论文 PDF 深读（每簇 2 篇）
   ↓
⑨ 簇深析 + 全局分析（注入候选池年份/类别画像补历史脉络）
   ↓
⑩ 导演大纲 → 分节并行写作（并发闸门 2，论断必须有所引文献支撑）→ 整体审校
   ↓
落盘 docs/survey/<slug>-<hash>.md + 注册侧边栏「📋 综述报告」分组
```

各阶段作用速查：

| 阶段 | 作用 |
|------|------|
| 种子分析 | 用一篇代表性论文锚定「任务范式」，综述只收同一/相近范式的论文；同时直取其参考文献补齐原生文献 |
| 查询规划 | 无种子时把任意语言主题翻译成英文检索查询组，驱动 Kaggle/本地库召回 |
| Kaggle 粗筛 | 在全量 arXiv 元数据里词法宽筛出万级候选（按主题三档 3千/1万/3万） |
| 贴合度熔断 | 候选池与主题词面错位时直接报错终止，防止 LLM 凭领域通识硬写 |
| 语义粗排 | 本地 embedding 给万级候选拍序，收窄到 300 篇供精排消化 |
| Reranker | Qwen3-Reranker 按「主题-论文」相关度精选 30 篇 |
| 抽取+范式门 | DeepSeek 逐篇打 relevance（<4 丢弃）和范式一致性（<5 剔除） |
| 聚类/深读 | 自动分主题簇，每簇精读 2 篇核心论文全文 |
| 写作/审校 | 每节强制横向对比与引用提炼，技术论断必须挂 [n] 且有文献支撑 |

## 前端参数怎么选

| 参数 | 默认 | 建议 |
|------|------|------|
| 种子论文 | 空 | 强烈推荐填领域代表作 arXiv 链接（或拖入 PDF）：范式更准、引文直取补原生文献 |
| 候选论文数 | 30 | 入门了解选 15-20，正式调研选 30+ |
| 回溯时长 | 1 年 | 技术演进类综述拉到 2-3 年（Kaggle 路支持全历史） |
| Reranker 精选 | 开 | 保持开 |
| 核心论文 PDF 深读 | 开 | 保持开（每簇多花几分钟换更实的对比分析） |
| Kaggle 本地快照粗筛 | 开 | 默认主路，保持开 |
| DeepXiv 外部检索 | 关 | 需要被引数标注或追最近一周新论文时勾选 |
| 粗筛规模 | 1 万 | 热门主题 3千够用；冷门/交叉方向选 3 万 |

## 进度反馈

提交后前端每 2.5 秒轮询任务事件：顶部是按阶段加权的进度条（抽取/写作阶段按
「17/30」粒度线性推进），中间是最新事件说明，下方是完整阶段事件流水（最近 80 条）；
「查看运行日志」可看服务器端原始日志。单次长 LLM 调用期间（全局分析/审校）会有
几十秒静默，属正常。生成约需 10-25 分钟（30 篇 + 深读），全程可点「取消任务」，
流水线在阶段边界协作式停止；40 分钟墙钟强制终止。

## 质量护栏与常见问题

- **主题漂移熔断**：候选池与主题词面覆盖率 < 0.2 时报错终止（阈值可用
  `DPR_SURVEY_RECALL_COVERAGE_MIN` 调整）。看到「召回池与主题词面覆盖率过低」时，
  换英文主题或提供种子论文重试。
- **防幻觉写作**：写手被约束「技术论断必须有所给 [n] 文献支撑，禁止使用资料外
  通识」；审校阶段会抽查正文论断与引用的对应性。
- **低相关警告**：终稿平均相关度偏低时，`report_meta.quality_warnings` 会记录提示，
  建议人工复核。
- **同题覆盖**：同一主题重复生成会覆盖旧报告（文件名由主题哈希决定），如需保留
  对比不同配置的产物，请在生成前备份 `docs/survey/` 下同名文件。
- **失败重试**：任务失败不扣已生成内容，直接重新提交即可；LLM 限流（429）由
  写作并发闸门兜底，一般无需干预。
